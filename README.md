# Biologi 2 – studieguide

En enkel studiesida på svenska om infektioner och smittspridning, immunförsvaret, nervsystemet och hormonsystemet.

Innehåller sökbara begrepp, läsanvisningar till Iris Biologi 2, övningsfrågor och lokalt sparade kunskapsmarkeringar.

Öppna https://therajushahi.github.io/biologi-2-studieguide/ eller ladda ner index.html för användning offline. Inga externa skript eller analysverktyg används.

Sidan är ett fristående studiestöd, inte en officiell NTI-produkt eller garanti för ett visst betyg.
